Vendas_TCC - Módulo de Vendas ERP (Etec Guarulhos)

Repositório TCC da Etec Guarulhos (2º Semestre / 2024 - 2026). Módulo de Vendas para um ERP corporativo completo, integrando cadastro de clientes, digitação de pedidos, motor de preços, gestão de devoluções e tela de balcão.
